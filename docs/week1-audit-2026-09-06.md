## SHIP BEFORE KICKOFF

**1. Refund the prompt/credit when Anthropic fails** — [FN] + [SQL] — *finding 22/15*
`supabase/functions/claude-proxy/index.ts:185` spends the weekly prompt (or a real $0.99 credit via `spend_ai_credit`) *before* the fetch at :199, and returns the upstream status verbatim at :232 with no compensation.
Why this week: Anthropic 429/529 peaks at exactly 1pm ET Sunday. Users retry, burn again, and `services/ai.ts:189` tells them "(Your prompt was not charged.)" while it was.
Fix: `consume_prompt` already returns `credit_spent` — capture it from `verdict`, and after the fetch, `if (!anthropicRes.ok) await sb.rpc('refund_prompt', { p_auth_id: userId, p_credit: verdict.credit_spent })`. New `refund_prompt` = decrement `prompt_usage.count` (floor 0) for `current_quota_week()`, or `ai_credits = ai_credits + 1` when `p_credit`. Wrap the fetch in try/catch and refund on throw too. Then fix the false copy at `services/ai.ts:189` **[OTA]**.

**2. Free tier is 10/week, not 10 lifetime** — [SQL] + [FN] — *finding 14*
`consume_prompt` buckets by `current_quota_week()` with no tier branch (`20260903030000_fix_prompt_quota.sql:62`); `free_lifetime_used` is written by the client and read by nobody.
Why this week: biggest signup week of the year, and every free account now carries recurring Opus COGS instead of a capped trial. The paywall's forcing function is dead during the highest-conversion week.
Fix: add `p_lifetime boolean` to `consume_prompt`; when true, do the atomic `UPDATE prompt_usage SET free_lifetime_used = free_lifetime_used + 1 WHERE user_id = v_uid AND free_lifetime_used < p_limit RETURNING`. claude-proxy already knows `tier` — pass `p_lifetime: tier === 'free'`. Extend `my_prompt_state()` to return the lifetime number and have `getRemainingPrompts()` (`services/promptQuota.ts:209`) use it for free users **[OTA]**.

**3. Tier/credit lockdown is a permanent no-op** — [SQL], one word — *finding 13*
`protect_tier_column()` is `SECURITY DEFINER` (`20260902200000_ai_credits.sql:19-24`), so `current_user` is always the owner (`postgres`) and the allow-list at the top always returns early. Anyone with the bundled anon key + their own JWT can `PATCH users` with `tier:'pro', ai_credits:9999`.
Why this week: the exploit is visible in the shipped JS bundle during peak download volume.
Fix: `CREATE OR REPLACE` the function **without** `SECURITY DEFINER` (a BEFORE trigger needs no elevation) — the guard then evaluates the real caller and the existing coerce-back-to-old logic keeps client upserts working. Do **not** reach for `REVOKE UPDATE (tier)` as the quick fix: `services/supabase.ts:52` still writes `row.tier` on purchase/restore paths and a column revoke would fail the whole upsert. Same one-word fix in `protect_prompt_usage_columns()` (`20260903030000_fix_prompt_quota.sql:19`). Then audit: `SELECT auth_id, tier, ai_credits FROM users WHERE tier <> 'free' OR ai_credits > 0;` against RevenueCat.

**4. Draft rooms have an invisible, unconfigurable 8-hour pick clock and zero push notifications** — [SQL] + [OTA] — *findings 18 + 20*
`pick_seconds` defaults to 28800 with no setter (`leagues_p1_finish.sql:11`); `pick_deadline` is never rendered in `app/leagues/draft/[id].tsx`; and `notify_hosted_event` sends `net.http_post` with **no Authorization/apikey header** (`:211-216`) to a function with no `[functions.hosted-notify]` block in config.toml, so verify_jwt rejects it and the trigger's `exception when others` swallows it silently.
Why this week: drafts are happening *now*. One idle drafter freezes eleven people with no timer, no push, and no explanation. This is the single most likely "the app is broken" support wave.
Fix: add `p_pick_seconds` to `create_hosted_league` (default 90 for live drafts) and thread it through `createHostedLeague` (`services/hostedLeagues.ts:16`); render a countdown from `league.pick_deadline` next to the on-the-clock banner (`draft/[id].tsx:226`) plus "autopick in N:NN". Separately, add the `apikey`/`Authorization: Bearer <service key>` headers the other crons already use (`schedule_daily_syncs.sql:59-63`) and set `app.hosted_notify_secret` via `ALTER DATABASE`; same missing header in `functions/league-recap/index.ts:75`.

**5. Unmapped rookies are visible but permanently undraftable** — [OTA] — *finding 19*
