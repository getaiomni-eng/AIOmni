## What this is

These are AIOmni's **proprietary formula** rankings — the 4-stage transparent algorithm defined in `services/rankings/aiomniEngine.ts`:

1. **Projected Points** — ADP/consensus rank converted to season point estimate via empirical decay curves, with format-specific scoring coefficients.
2. **Value Over Replacement (VOR)** — subtracts positional replacement level (set by league construction) so positional scarcity is captured.
3. **Time-Value Factor (TVF)** — for dynasty, applies age-based depreciation curves to compute Expected Lifetime Value.
4. **Tier Clustering** — natural cliff detection on VOR gaps; lower tier number = better.

Pulse rankings (the AI-blended community consensus shown on the *AIOmni Pulse* tab) are computed at runtime from live Sleeper + ESPN + Yahoo + MFL + Fleaflicker ADP and are **not** in this document — they live in `services/rankingsData.ts:fetchBlendedConsensus()` and need a separate live-fetch run.

**Columns:** Pos# = rank within position · # = overall rank · T = tier · Score = raw synthesis score · Age = age-curve multiplier · Team = team-change adjustment · Rk = rookie boost · Opp = opportunity adj (snap share + target trend).
