## What this is

**AIOmni Pulse** is the AI-blended community-consensus surface (see `services/rankingsData.ts:fetchBlendedConsensus`). For *redraft*, Pulse blends Sleeper + ESPN + Yahoo + MFL + Fleaflicker ADP. For *dynasty*, the dominant community signal is **KeepTradeCut (KTC)** trade values — that's what this doc uses, with top-25 cuts per position.

- **Value** = raw KTC trade value (higher = more valuable; ranges roughly 0–10,000).
- **7d** = 7-day trend in KTC value (negative = losing value, positive = gaining).
- **Tier** = KTC's tier bucket (1 = elite).
- KTC values are roughly PPR-equivalent — dynasty Half/Standard variants are not a separate market in the community, so they're not produced here. The AIOmni Formula doc covers the per-scoring-format dynasty variants algorithmically.
